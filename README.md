# 🏙️ Smart Civic Platform

Smart Civic Platform is a web-based civic complaint management system that helps citizens report problems in their city and allows administrators to manage and track those complaints efficiently.

The platform provides a simple digital connection between citizens and civic authorities.

---

## 🚀 Features

### 👤 Citizen Features

- User Registration
- Secure Login
- JWT-based Authentication
- Report Civic Problems
- Select Complaint Category
- Add Problem Description
- Add Problem Location
- Upload Problem Images
- Track Complaint Status
- View Previous Complaints
- Receive Notifications
- Logout

### 🛠️ Admin Features

- Admin Login
- View All Complaints
- Manage Citizen Complaints
- Update Complaint Status
- Monitor Civic Issues
- View Complaint Details
- Manage Reported Problems
